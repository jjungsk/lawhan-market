### 트래픽 추정
- 월 트래픽 한도 3.5GB 기준, 페이지당 평균 1~2MB 가정 시 월 방문(페이지뷰) 약 2,000~3,500회, 일 평균 60~120회 수준으로 추정되는 소규모 트래픽.
- 동시접속자는 피크 시간대에도 한 자릿수~10명 내외로 예상.
- 정확한 일별 방문자 추이는 카페24 관리자의 "상세통계/일별전송량보기" 팝업에서 직접 확인 필요(인증 토큰 포함 URL이라 자동 조회는 제한됨).

## 3. AWS 이전 시 추천 구성 및 예상 비용 (서울 리전 ap-northeast-2, 온디맨드 기준)

| 항목 | 카페24(현재) | AWS 추천 구성 | 월 예상 요금(USD) |
|---|---|---|---|
| 웹서버 | 공유호스팅(CPU/메모리 비공개) | EC2 t3.small (2vCPU, 2GB) 온디맨드 | \$18.98 |
| 디스크 | 웹 3,000M | EBS gp3 20GB | \$1.82 |
| 게시판 파일 저장소 | 없음 (추가 필요) | S3 Standard 20GB | \$0.50 |
| 이미지 캐싱/CDN | 없음 | CloudFront (월 1TB + 1천만 요청까지 무료) | \$0.00 |
| SSL 인증서 | 38,500원/년 별도 | ACM 인증서 (CloudFront/ALB 연동 시 무료) | \$0.00 |
| **합계(온디맨드)** | **약 8,000원/월** | — | **약 \$21.30 (약 30,000원, 1,400원/\$ 가정)** |

### 비용 절감 옵션
- **EC2 t3.micro**로 축소: 온디맨드 약 \$9.5/월 (트래픽이 매우 낮을 때)
- **1년 약정 Savings Plan** 적용 시 EC2 비용: \$18.98 → 약 **\$9.64/월**
  - 이 경우 총합 약 **\$12/월 (약 17,000원)** 수준까지 절감 가능, 카페24와 비슷한 수준

### DB 분리 옵션 (선택)
- RDS MariaDB db.t3.micro, 단일 AZ, 20GB 스토리지, RDS Proxy 미사용 기준 약 **\$39.85/월** 추가
- 초기에는 EC2 내 MariaDB로 함께 운영하고, 트래픽/안정성 요구 증가 시 RDS로 분리 권장

## 4. 종합 의견
- 순수 비용은 카페24 공유호스팅이 AWS보다 저렴하지만, AWS는 서버 자원을 독점 할당받아 성능·확장성·커스터마이징 측면에서 유리.
- 게시판 첨부파일은 S3 + CloudFront로 분리하여 EC2 부하 없이 서빙 가능.
- 예산을 카페24와 비슷하게 맞추려면 t3.micro + 1년 Savings Plan 조합을, 여유가 있다면 t3.small 온디맨드로 시작 후 트래픽을 보며 조정하는 방향을 권장.
